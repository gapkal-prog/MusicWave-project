# لایهٔ استریم نزدیک به موکاپ WAVE

## اسلایدر انتشارها
در تنظیمات بلوک «اسلایدر انتشارهای MusicWave»:
- پیوند **مشاهده همه** و برچسب آن
- **شکل تصویر** (مربع / افقی / عمودی / دایره)
- **اندازه تصویر** (کوچک / متوسط / بزرگ)
- **تب‌های فیلتر** مثل Today / Week / Korean Indie

هر خط تب به این شکل است:

```
امروز|orderBy:date
هفته|orderBy:views
ایندی کره|taxonomy:mw_genre:korean-indie
```

تب‌ها لینک واقعی هستند (`?mw_tab_…=`) و بدون جاوااسکریپت کار می‌کنند.

همین تب‌ها روی **ویترین انتشارها** هم در پنل تنظیمات موجود است.

## سربرگ سراسری (یک انتخاب برای کل سایت)
از **نمایش → سفارشی‌سازی → سربرگ و پوسته استریم** یا **نمایش → سربرگ MusicWave**:

- سربرگ ساده افقی
- وسط‌چین
- کمینه
- استریم (ریل شروع اینلاین — پیش‌فرض، شبیه موکاپ WAVE)
- استریم با ریل در انتها

قالب‌ها همه `header` می‌مانند؛ وردپرس همان انتخاب را همه‌جا رندر می‌کند. ویرایش آیتم‌های ریل/جستجو/VIP در ویرایشگر سایت → بخش‌های قالب.

## متن هم‌زمان (Live Sync Lyrics)
افزونهٔ شخص ثالث استفاده نمی‌شود. مدل پلتفرم‌های بزرگ: **LRC خودِ انتشار** در متای `mw_lyrics_lrc`.

بلوک قالب `متن هم‌زمان MusicWave` خط فعال را با پخش‌کننده هم‌تراز می‌کند. بدون JS همهٔ خطوط خوانا می‌مانند. حالت‌ها در تنظیمات بلوک: نورافکن / کارائوکه / ساده.

حقوق متن با فروشنده است؛ شبکهٔ خارجی متن نداریم.

## صفحهٔ سینگل
قالب `single-mw_release` سربرگ استریم، هیرو، اکشن‌ها، فهرست قطعهٔ وینیل و بلوک متن هم‌زمان را کنار هم می‌چیند.
